# 🐍 Python Crash Course: Notas y Soluciones

Este espacio está dedicado a documentar mi progreso a través del libro **"Python Crash Course: A Hands-on, Project-based Introduction to Programming"** de Eric Matthes.

Mi objetivo con este repositorio es doble:
1. **Consolidar conocimientos:** Escribir mis impresiones y lo que aprendí en cada capítulo.
2. **Práctica constante:** Guardar mis soluciones a los ejercicios propuestos para ver mi evolución técnica.

---

## 📂 Estructura del Repositorio

Planeé que el proyecto esté organizado por capítulos para facilitar la navegación y la ubicación tanto de las notas de mis impresiones como de la solución de los ejercicios:

* `/capitulo_XX/`: Contiene los scripts de práctica y ejercicios.
* `/capitulo_XX/notas.md`: Mis reflexiones, conceptos clave y "Aha! moments" de cada sección.
* `/proyectos/`: Espacio dedicado a los proyectos finales del libro (Alien Invasion, Data Visualization, Django).
