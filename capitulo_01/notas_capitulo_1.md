# Notas del capítulo 1

En este capítulo se introducen los conceptos sobre lo que es Python y cómo se puede poner puesta a punto nuestro entorno para trabajar con este lenguaje de programación.

Para ello necesitaremos: Un editor de código o un IDE y el interprete de Python. También sse mencionan cómo debe instalarse dependiendo del sistema operativo en el que estés trabajando, ya sea Windows, macOS o Linux. En mi caso personal, estoy trabajando sobre W10, por lo que mis apuntes seguirán esa línea en cuanto a configuración de ambientes se refiere.

Cómo páginas de interes que te permitirán configurar tu entorno tenemos:

- https://code.visualstudio.com/ : Página oficial de Visual Studio Code, donde puedes descargar el editor y encontrar extensiones útiles para Python.
- https://www.python.org/downloads/ : Página oficial de Python, donde puedes descargar la última versión del lenguaje de programación.
- https://code.visualstudio.com/docs/languages/python : Documentación oficial de Visual Studio Code para configurar Python, incluyendo la instalación de la extensión de Python y cómo configurar el entorno de desarrollo.

Como dato de color mencionaremos `pip` y `uv` que son herramientas de gestión de paquetes para Python. `pip` es el gestor de paquetes oficial de Python, mientras que `uv` (o `uvicorn`) es un servidor ASGI para aplicaciones web en Python. Ambos son esenciales para instalar y gestionar dependencias en proyectos de Python. últimamente se ha vuelto muy popular `uv` por su rendimiento y facilidad de uso en aplicaciones web modernas, especialmente con frameworks como FastAPI.

Adicionalmente, se instalaron las extensiones de Python y Pylance en Visual Studio Code para mejorar la experiencia de desarrollo, proporcionando características como autocompletado, linting y depuración.

Por último, se mostró cómo crear un archivo `hello.py` con un simple programa que imprime "Hello, World!" corriéndolo tanto desde terminal como desde el editor de código para verificar que todo esté funcionando correctamente.
